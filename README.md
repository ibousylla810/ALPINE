# ALPINE - Générateur IA de Documentaires

![ALPINE Logo](https://img.shields.io/badge/ALPINE-Générateur%20IA-blue?style=for-the-badge&logo=video&logoColor=white)

ALPINE est une plateforme web moderne qui utilise l'intelligence artificielle pour générer des documentaires professionnels à partir d'une simple description textuelle.

## 🚀 Fonctionnalités

- **Génération automatique** de documentaires jusqu'à 10 minutes
- **Interface intuitive** avec design professionnel et futuriste
- **Personnalisation avancée** : style, ton, durée, sujet
- **Prévisualisation en temps réel** du contenu généré
- **Responsive design** optimisé pour tous les appareils
- **Scripts détaillés** avec structure narrative professionnelle

## 🎯 Types de documentaires supportés

- **Scientifique** : Recherches, découvertes, innovations
- **Historique** : Événements, personnages, époques
- **Nature & Environnement** : Écosystèmes, climat, biodiversité
- **Social & Société** : Enjeux contemporains, culture
- **Technologie & Innovation** : IA, robotique, futur
- **Biographique** : Portraits, parcours de vie

## 🛠️ Technologies utilisées

- **Frontend** : HTML5, CSS3, JavaScript ES6+
- **Design** : Interface moderne avec animations CSS
- **Typographie** : Google Fonts (Inter)
- **Responsive** : Design adaptatif mobile-first
- **Hébergement** : GitHub Pages
